# Payzo releases

Signed installers for Payzo, the Philippine payroll app.

Payzo checks this page once a day for a newer version, and an Admin installs it from **Settings › Updates**. Every installer is signed: Payzo refuses one that has been changed or doesn't come from us, and never goes back to an older version.

For a computer without internet, download the installer and its `.sig` file from the latest release, copy both to that computer, and install them from **Settings › Updates**.

There's no code or customer data here.
